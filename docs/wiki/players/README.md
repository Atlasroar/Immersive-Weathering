This fork targets Minecraft 1.20.1 on Fabric. Some systems have reported bugs;
read troubleshooting before depending on them in an existing world. Modpacks
can override settings, tags, and recipes, so the same mod may behave differently
in different packs.

Reproducible checks and reported outcomes live in the developer guide:
[in-game test sheet](../developers/Feature-testing.md) and
[test results](../developers/Test-results.md). A recorded result applies to its
documented setup and round, not every modpack or later release.
