# Immersive Weathering wiki

**A world that weathers with time.** Learn how natural weathering, ground cover,
plant growth and weather interactions fit together in this Fabric fork.

## Project scope

This project maintains **Minecraft 1.20.1, Fabric and Java 17** in one root
Fabric Loom project. Moonlight Lib remains required for its functional APIs.
Forge, NeoForge and multiloader support are outside this fork's scope.

The mod covers weathered building materials and restoration tools; bark, leaf
piles, soils and plants; snow and sand layers; frost, thin ice and icicles;
fire interactions, sandstorms, freezing wind and cold thunder snowstorms.
Weather features do not add a player-temperature system. Availability and
behavior depend on configuration, datapacks and supported block variants.
